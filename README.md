# ml-from-scratch

题库见[牛客华为AI岗机考真题](https://www.nowcoder.com/exam/oj/ta?page=1&tpId=37&type=390)，仓库提供题解的 numpy 解法，以下是2026年华为笔试的经验，仅供参考，最后本人主管面没过。

## 心得

1. 熟悉 numpy 的语法，妙用 numpy 进行矩阵的运算，可以缩短机考编码需要的时间。
2. 看往年大题题库，总结常考题型，如 kmeans / knn / tranformer 等等算法是常见的。试着练到不看题解自己能写的水平。有些题目的算法背景有点复杂但是题目很简单，重点在于理解算法实现的流程。
3. 机考小题的知识点很多很杂，也许可以照着机器学习和深度学习的教材书目录把考点串联起来。
4. 面试的手撕可能会考ai相关也可能是力扣简单题，本人当时一面手撕的题目和词频（见nlp文件夹）相关，二面手撕单调栈。
5. 一面问transformer的架构以及公式，所以学有余力要多看看论文原文。
6. 二面问简历上的项目，所以简历上的每句话都要认真准备。面试华为前也多面面其他公司刷“面感”，查漏补缺。

- 本人自己学过机器学习，当时用numpy手撕过pca和lda。考前只是做了仓库里的题型，所幸机考大题遇到自己会的，大题能完全做出来两道。个人评估半个月的时间，0基础是能够速通机考大题的。
